07 / DATA & METHODOLOGY

From Network Flows to Model-Ready Data

Beta5G uses the UNSW-NB15 dataset and a structured training pipeline combining categorical encoding, feature engineering, adversarial augmentation, and SMOTE oversampling.

DATASET OVERVIEWUNSW-NB15
175,341TRAINING RECORDS
82,332TESTING RECORDS
42RAW FEATURES
9 + NORMALCLASSES

Raw network-flow characteristics include duration, byte counts, packet counts, TTL values, TCP flags, and connection-tracking counters.

FEATURE ENGINEERING

42 raw features + 8 derived features

Eight derived ratio and behavior features were appended to the original feature set. They amplify asymmetric traffic patterns characteristic of DoS and reconnaissance attacks, supported by XGBoost importance scores.

13 / LIMITATIONS & FUTURE

Research With Clear Boundaries.

Beta5G demonstrates a practical Fog–Cloud security architecture, while its current limitations define the next steps for research and deployment.

CURRENT LIMITATIONSWHAT THE PAPER IDENTIFIES
01

DATASET SCOPE

UNSW-NB15 does not contain Modbus/MQTT-specific attack vectors.

OT protocol-specific attacks therefore rely on anomaly detection rather than supervised classification.
02

CLASS SIMILARITY

XGBoost classification is constrained by similarity between some attack classes.

Exploits / Fuzzers
03

SHAP COMPUTATION OVERHEAD

SHAP adds approximately 15–25 ms per alert at the Cloud layer under sustained high-rate attacks.

04

DEPLOYMENT SCALE

The current work describes a Docker-based research prototype. Future deployment should evaluate the architecture on constrained edge hardware.

WHERE BETA5G GOES NEXTFUTURE RESEARCH DIRECTIONS
01

TON_IoT

Evaluate the architecture with the TON_IoT dataset.

02

SWaT

Expand evaluation using the SWaT industrial control system dataset.

03

REAL-TIME STREAMING

Explore WebSocket-based real-time streaming for live system communication.

04

EDGE DEPLOYMENT

Evaluate deployment on Raspberry Pi-class Fog hardware.

05

SHAP OPTIMIZATION

BATCHED / ASYNCHRONOUS SHAP

Future batching or asynchronous handling could reduce queue build-up during sustained high-rate attacks.

RESEARCH ROADMAP

CURRENT RESEARCH↓UNSW-NB15↓BROADER DATASETS↓TON_IoT · SWaT↓REAL-TIME STREAMING↓WebSocket↓LIGHTWEIGHT FOG DEPLOYMENT↓Raspberry Pi-class Fog↓OPTIMIZED EXPLAINABILITY↓Batched / Async SHAP
Limitations are not gaps to hide—they define the next experiments.Beta5G is positioned as a research prototype with a clear path toward broader industrial evaluation.
