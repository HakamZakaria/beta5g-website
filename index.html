01

The Project

Beta5G proposes a deployable and explainable IDS designed for smart-factory environments.

The system moves lightweight detection close to the network source at the Fog layer and delegates deeper analysis to the Cloud. This reduces unnecessary traffic forwarding while preserving advanced classification and explainability.

FogFast local filtering
CloudDeep multi-class analysis
SHAPExplainable decisions
DashboardRole-based monitoring

AI & Cybersecurity

Fog binary filter optimized for high recall.

Unsupervised anomaly detection trained on normal traffic.

XGBoost

Cloud multi-class classification across nine attack categories.

SH

SHAP

Per-feature explanations for security decisions.

Minority-class oversampling for imbalanced data.

Noise, slowdown and padding perturbations used during training.
