## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `beta5g-website`.
2. Upload all files from this folder.
3. Open repository Settings → Pages.
4. Select the `main` branch as the publishing source.
5. GitHub will provide the live `github.io` URL.

GitHub Pages publishes static HTML/CSS/JS directly from a repository.
For a custom domain, configure it from the repository Pages settings and your DNS provider.

## QR Code
Once the final public URL is known, generate a QR code pointing to that URL. Do not point the QR code directly to a temporary file.
